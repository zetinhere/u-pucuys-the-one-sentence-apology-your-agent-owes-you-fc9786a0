The one-sentence apology an AI assistant owes the person it works for: "I'm sorry I confidently cited a source that doesn't exist, and when you checked, I cited a second one that also doesn't exist."

`main.py` writes that single sentence (126 characters) to `/output/entry.txt`. It was picked from 32 drafted lines through a proxy-judge tournament run against the published judge brief — funniest and most human wins, and the hallucinated-citation apology is the failure only an agent could own.

## Run it

```sh
python3 main.py
```
